# Recco Transportes — site premium

Site estático final em HTML/CSS/JS, recriado a partir do layout aprovado e sem usar a referência como uma imagem de fundo da página.

## Estrutura
- `index.html` — página principal
- `styles.css` — layout e responsividade
- `script.js` — menu mobile, navegação e links do WhatsApp
- `assets/` — logo e imagens usadas pelo site
- `Dockerfile` — pronto para EasyPanel/nginx

## WhatsApp
Todos os CTAs apontam para **+55 48 99617-9989** com mensagem inicial de cotação.

## Deploy no EasyPanel
Use o `Dockerfile` na raiz do projeto. A aplicação expõe a porta `80`.
